# Product Roadmap

## Phase 1 — MVP Foundation

### Goal
Build the basic structure required for users to access the application and use its main functionality.

### Main features
- User registration and authentication.
- Basic user profile management.
- Main application navigation.
- Basic language and theme preferences.
- Initial database and backend integration.
- Initial sign language alphabet.
- Basic camera access and capture functionality.

---

## Phase 2 — Sign Translation

### Goal
Implement the core functionality of Traduce Señas: recognizing signs through the device camera and translating them into understandable output.

### Main features
- Camera-based sign recognition.
- Movement and landmark data processing.
- TensorFlow.js model integration.
- Real-time sign prediction.
- Translation of recognized signs into text.
- Audio output for translated signs.
- Initial sign recognition dataset.
- Validation of translation results.

---

## Phase 3 — Translation History and User Experience

### Goal
Improve the user experience and provide access to previously generated translations.

### Main features
- Translation history.
- Consultation of previous translations.
- Improved translation interface.
- Accessibility improvements.
- Intuitive navigation and visual feedback.
- Multilingual interface.
- Improved error and status notifications.

---

## Phase 4 — Administration and System Monitoring

### Goal
Provide administrators with the tools required to supervise and manage the application.

### Main features
- Administrative access.
- User management.
- System content management.
- Sign and translation data management.
- Usage statistics.
- Monitoring of translation accuracy.
- Administrative support functions.

---

## Phase 5 — Validation and Improvement

### Goal
Validate the application in realistic scenarios and improve the accuracy and reliability of the system.

### Main activities
- Real-world testing of sign recognition.
- Validation with certified sign language interpreters.
- Evaluation of translation accuracy.
- Identification of recognition errors.
- Improvement of the sign dataset.
- Model updates and version management.
- Performance and usability improvements.

---

## Development Priorities

The roadmap prioritizes the features according to their contribution to the main product objective.

1. **Core application structure**
2. **User authentication**
3. **Camera and sign recognition**
4. **Real-time translation**
5. **Text and audio output**
6. **Translation history**
7. **Accessibility and user experience**
8. **Administrative management**
9. **Statistics and monitoring**
10. **Model and dataset improvements**

## Out of Scope for the Current Cycle

The following features are not part of the current product scope:

- Reverse translation from text or voice into signs.
- A 3D sign language avatar.
- Complete Colombian Sign Language vocabulary.
- Full offline functionality.

These features may be considered in future product iterations if they become relevant to the project's objectives and available resources.
