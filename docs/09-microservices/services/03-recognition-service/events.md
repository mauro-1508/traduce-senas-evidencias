# Events — Recognition Service

> Asynchronous events over RabbitMQ: exchange `traduce.events` (topic), routing key `recognition.<EventName>`.
> Typed payloads are in `packages/shared/src/events/contracts.ts`; the catalog is in `02-domain/domain-events.md`.
> This file lists what the code does **today**, and the events of the target model that the code does not have yet.

---

## Events this service PUBLISHES

| Event | Routing key | When | Payload | Consumers |
|-------|-------------|------|---------|-----------|
| `TranslationProduced` | `recognition.TranslationProduced` | A translation is saved (`POST /api/translations`) | `{translationId, userId, gloss, text, occurredAt, eligible}`, plus `mode` and `sessionId` when the request sends them | analytics (usage event `TRANSLATION_COMPLETED`), profile (achievement progress) |

`gloss` is the input text of the translation and `text` is the output text. The event carries text only, never video or samples.

It is published directly after the insert, with a best-effort publish: if the bus fails, the translation stays saved and the failure is logged.

### Event example: `TranslationProduced`

```json
{
  "eventId": "7b8c9d0e-0000-4000-8000-000000000001",
  "type": "recognition.TranslationProduced",
  "occurredAt": "2026-08-31T16:02:19.000Z",
  "payload": {
    "translationId": 15,
    "userId": 42,
    "gloss": "HOLA",
    "text": "Hola",
    "occurredAt": "2026-08-31T16:02:19.000Z",
    "eligible": true,
    "mode": "words",
    "sessionId": "3f2b8c1e-5d4a-4b7e-9c10"
  }
}
```

## Events this service CONSUMES

| Event | Published by | Queue | What recognition does |
|-------|--------------|-------|-----------------------|
| `lexicon.SignPublished`, `lexicon.SignWithdrawn` (pattern `lexicon.*`) | lexicon | `recognition-service.lexicon-events` | Only logs them. The sign catalog is not used yet |
| `iam.UserDeleted` | iam | `recognition-service.user-deleted` | Deletes the user's translations, unlinks the user from the gesture samples (`recorded_by` is cleared, the samples are kept) and records the user in `erased_users`, so later writes with an old token answer `401 ACCOUNT_DELETED` |

## Target events (not in the code yet)

The events below belong to the target model of `02-domain/domain-events.md`. The code does not publish or consume them.

| Event | Routing key | When it would be emitted | Payload (key fields) | Consumers |
|-------|-------------|--------------------------|----------------------|-----------|
| `TranslationSessionStarted` | `recognition.TranslationSessionStarted` | The user turns translation mode on and the camera is ready | `{sessionId, userId, outputMode, modelVersion, startedAt}` | analytics |
| `RecognitionFailed` | `recognition.RecognitionFailed` | Low confidence, sign outside the vocabulary or engine error | `{sessionId, reason, confidence, threshold, occurredAt}` | analytics, profile |
| `TranslationSessionEnded` | `recognition.TranslationSessionEnded` | Translation mode turned off | `{sessionId, userId, endedAt, translationCount, durationSeconds}` | analytics |
| `TranslationSessionInterrupted` | `recognition.TranslationSessionInterrupted` | Camera denied, connection lost, engine error | `{sessionId, userId, reason, interruptedAt, translationCount}` | analytics, profile |
| `TranslationDeleted` | `recognition.TranslationDeleted` | The user deletes a history entry | `{translationId, sessionId, userId, deletedAt}` | analytics |
| `RecognitionModelTrained` | `recognition.RecognitionModelTrained` | A training run finishes and is registered | `{modelId, version, trainedBy, trainedAt, sampleCount, signCount, accuracy}` | iam (audit) |
| `RecognitionModelPublished` | `recognition.RecognitionModelPublished` | An administrator activates a model version | `{modelId, version, previousModelId, accuracy, storageReference, publishedAt}` | analytics, iam (audit), the app |
| `GestureSampleCaptured` | `recognition.GestureSampleCaptured` | A sample is recorded in a capture session | `{sampleId, captureSessionId, signCode, sampleType, recordedBy, consentGrantedAt, consentTermsVersion, capturedAt}` | iam (compliance audit) |
| `GestureSampleValidated` | `recognition.GestureSampleValidated` | A linguist approves a sample | `{sampleId, validatedBy, validatedAt}` | the training pipeline |
| `CaptureSessionDiscarded` | `recognition.CaptureSessionDiscarded` | A batch is discarded or a collaborator withdraws authorization | `{captureSessionId, sampleCount, reason, discardedBy, discardedAt}` | iam (audit) |
| `TrainingSampleAnonymized` | `recognition.TrainingSampleAnonymized` | A sample is persisted under an irreversible pseudonym (only if INV-010 is kept, ALIGN-02) | `{sampleId, anonymousSubjectId, gloss, anonymizedAt}` | iam (audit) |

The session events would be emitted from the runtime session of the service. The `sessionId` is generated by recognition and is not persisted: `TranslationSession` has no table (ALIGN-01).

Target consumers, not implemented: `iam.ConsentGranted`, `iam.ConsentRevoked` (discard the capture sessions of a collaborator) and `iam.AccountDeletionRequested`. The code has no consent events; the deletion event it handles is `iam.UserDeleted`.

## Delivery guarantees

| Guarantee | Value | Implication |
|-----------|-------|-------------|
| At-least-once | Yes for consumed events | The broker can redeliver an event, so the consumer must tolerate a second copy |
| At-most-once | No | |
| Exactly-once | No | |

`TranslationProduced` has no outbox: a failed publish is only logged, so a translation can exist without its event. The target model uses a transactional outbox in the `recognition` database.

## Error handling

- Messages a consumer rejects are kept in `<queue>.dead` (for example `recognition-service.user-deleted.dead`). The `/health` of the service reports `dead_letters` when those queues have messages.
- The `iam.UserDeleted` handler retries without a limit while it fails. `/health` reports `consumer_retrying` after 10 minutes of retries.
- The target policy (3 to 5 retries with exponential backoff, a `recognition.main.dlq` queue and 7-day retention) is not implemented as written.
